# SmartRetail Analytics Dashboard — v0.5

Dashboard React + TypeScript para consumo da SmartRetail Analytics API.

## Desenvolvimento

```powershell
cd frontend/analytics-dashboard
npm install
npm run dev
```

A interface local fica em:

```text
http://localhost:5173
```

API padrão:

```text
http://localhost:8082
```

É possível alterar a API com:

```text
VITE_API_URL
```

## Visões iniciais

- receita total;
- total de pedidos;
- ticket médio;
- itens vendidos;
- clientes únicos;
- produtos únicos;
- receita por data/canal/local;
- tabela detalhada da camada Gold.
